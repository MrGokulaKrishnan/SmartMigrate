Enterprise Security

Security is the foundation, not an afterthought.

01

Host-Side Authorization Source of Truth

The host machine retains ultimate authority. Every requested capability (screen, mouse, keyboard, files, clipboard) is explicitly granted or revoked by the host operator.

02

Cryptographic Numeric & QR Pairing

Pairing uses Advapi32 RtlGenRandom cryptographically secure 6-digit codes with constant-time equality checks and strict 3-attempt brute-force lockouts.

03

Zero Secrets or Screen Frames in Logs

Strict privacy enforcement guarantees no private keys, pairing tokens, passwords, screen frames, or raw file paths ever reach application logs or telemetry.

04

Replay & Path Traversal Barriers

Monotonic SMP/1 sequence tracking prevents packet replay attacks, while NTFS sanitization blocks directory traversal (..), null bytes, and Windows reserved names.

Technical Architecture

Smart Migrate Protocol (SMP/1) & MigRoute Core

SMP/1 Framing

Type-safe Protobuf and binary envelope format. Enforces monotonic sequence numbers, 16 MiB payload ceiling, and session authorization tokens on every packet.

MigRoute Systems Engine

Engineered in 100% memory-safe Rust with zero unsafe abstractions. Validated with 63 rigorous unit tests covering crypto, state machines, and transport resilience.

Native Platform Adapters

Direct Win32 Graphics Capture and SendInput APIs on Windows; hardware-accelerated MediaCodec and Jetpack Compose on Android.

Frequently Asked Questions

Common questions & technical details

Q

Does Smart Migrate require an internet connection?

No. When devices are on the same local Wi-Fi or LAN subnet, Smart Migrate routes all files, remote control, and streams directly peer-to-peer at full line speed (0.4 ms RTT).

Q

How does resumable file transfer handle disconnections?

Files are chunked into 1 MiB blocks. If network drops or the app restarts, transfer resumes from the exact missing chunk index. Final files are verified against SHA-256 before atomic commit.

Q

Is mobile battery consumption high during remote control?

Smart Migrate features automatic Battery Awareness. When battery drops below 20%, it reduces background polling and switches video decode to low-power hardware modes.
