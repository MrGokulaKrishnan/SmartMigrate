Network Transports

How connections work

Multiple transport layers tailored for high throughput, minimal latency, and zero cloud dependency.

Same Wi-Fi

Active

Both devices on the same local subnet. UDP broadcast discovers peers automatically at full line speed (0.4 ms RTT). No internet required.

Wi-Fi Hotspot

Active

One device activates a mobile hotspot; the other connects directly. Ideal for field transfers, zero router dependencies, and isolated connections.

Direct P2P

Active

Peer-to-peer TCP channel negotiates direct socket connectivity without intermediary hops. Maximum transfer rate limited only by device hardware.

Internet Relay

Planned

Encrypted STUN/TURN fallback relay for cross-network scenarios. Fully optional — all local network streaming and file transfers function offline.

Enterprise Security

Security is the foundation, not an afterthought.

Engineered with zero-trust architecture, host authorization, and robust defensive protocol barriers.

01

Host-Side Authorization Source of Truth

The host computer retains ultimate authority. Every requested capability (screen mirror, touchpad, keyboard dispatch, file system, clipboard) is explicitly granted or revoked by the host operator. Remote clients cannot escalate privileges.

02

Cryptographic Numeric & QR Pairing

Pairing uses cryptographically secure 6-digit numeric tokens generated with Advapi32 RtlGenRandom, constant-time equality checks, and strict 3-attempt brute-force lockouts to prevent unauthorized access.

03

Strict Zero-Secrets Logging Policy

Strict privacy enforcement guarantees no private keys, pairing tokens, passwords, screen frames, or raw user file paths ever reach application logs or telemetry records.

04

Replay & Path Traversal Defensive Barriers

Monotonic SMP/1 sequence tracking prevents packet replay attacks, while strict path sanitization blocks directory traversal (..), null bytes, and Windows reserved device names.

Frequently Asked Questions

Common questions & technical details

Everything you need to know about Smart Migrate networking, security, and migration mechanics.

Does Smart Migrate require an internet connection?

No. When devices are on the same local Wi-Fi or LAN subnet, Smart Migrate routes all files, remote control, and streams directly peer-to-peer at full line speed (0.4 ms RTT). Zero internet connection is required.

How does resumable file transfer handle network drops?

Files are streamed in 1 MB blocks with state checkpoints. If the connection flickers or the application restarts, transfer resumes precisely from the missing chunk index. Files are SHA-256 verified before commit.

How does the 60 FPS display stream achieve low latency?

The MigRoute core utilizes native DXGI Desktop Duplication on Windows with direct GPU hardware encoding, bypassing user-space buffer copying. The stream delivers sub-frame latency over 5 GHz Wi-Fi.

Is battery consumption high during remote control?

Smart Migrate features automatic Battery Awareness. When battery drops below 20%, it reduces background polling and switches video decode to low-power hardware modes on your phone.
