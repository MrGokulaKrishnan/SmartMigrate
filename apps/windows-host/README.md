# Smart Migrate Windows Host

This is a Tauri 2 + React application shell. It includes a working local navigation model and a non-sensitive Rust `host_status` command, styled with the same liquid-glass system as the website.

It may not expose screen capture, remote input, file access, or clipboard synchronization until the corresponding MigRoute authorization path and native adapter tests exist.

## Run after installing prerequisites

```powershell
pnpm install
pnpm --filter @smart-migrate/windows-host tauri dev
```
